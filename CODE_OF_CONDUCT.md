# Code of Conduct

This project adopts the Contributor Covenant, version 2.1. The maintainer
should verify the canonical text and license at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ before
release. This project-specific summary is intended to make the expectations
clear; the canonical covenant governs if there is any discrepancy.

## Our standard

Participants are expected to act respectfully, welcome differing experience
and viewpoints, give and receive constructive feedback, and focus on what is
best for the community. Harassment, discrimination, intimidation, personal
attacks, sexualized conduct, and publishing another person's private
information without permission are unacceptable.

## Scope

These expectations apply in project spaces, public discussions representing
the project, and other interactions where someone is acting on behalf of the
project.

## Reporting

Report conduct concerns privately to **[MAINTAINER CONTACT ADDRESS]**. Include
the relevant context and any links or records that can help the maintainers
understand the concern. Do not include passwords, API keys, AWS credentials,
or unrelated private infrastructure data.

## Enforcement

Maintainers will review reports, respect confidentiality as far as practical,
and determine an appropriate response. Actions may include a private warning,
removal or editing of inappropriate content, temporary participation limits,
or permanent exclusion from project spaces. Maintainers will explain the
reason for an enforcement decision where doing so is safe and appropriate.

## Maintainer responsibilities

Project maintainers are responsible for clarifying and enforcing these
standards fairly and consistently. Replace the contact placeholder before
public release.
