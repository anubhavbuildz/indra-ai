# Support

Start with the [README](README.md), [API overview](docs/api.md),
[architecture](docs/architecture.md), and [security notes](docs/security.md).
The FastAPI interactive documentation is served at `/docs` in development.

For usage questions, open a GitHub issue using a clear question and the
relevant redacted configuration. For reproducible defects, use the bug
report template and include the Python version, operating system, steps, and
redacted error output. Feature ideas should explain the user problem and
expected behavior.

Do not post API keys, `.env` files, AWS credentials or account secrets,
Terraform state/plan files, or sensitive infrastructure configuration in an
issue. Security vulnerabilities should be reported privately as described in
[SECURITY.md](SECURITY.md), not in a public issue.

This is an early-stage project without a committed response-time guarantee.
